# 원소 원정대 (The Element Expedition) · v0.3

GBA 스타일 원소 **퀴즈 채집** RPG. 1번 수소 ~ 36번 크립톤(1~4주기)을 채집해 **원소 도감 = 주기율표**를 완성한다. 수업용.
레벨·HP 같은 육성 요소는 없다. 정체를 모르는 자연 상태의 원소를 만나면 **실생활 수수께끼**가 나오고, 맞히면 정체가 밝혀지며 채집된다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ 폴더 생성 → 정적 웹서버(학교 서버, GitHub Pages 등)에 그대로 올리면 됨
```

## 조작

| 키 | 기능 |
|---|---|
| 방향키 / WASD | 이동, 보기 선택 |
| Z / Space | 확인, 말 걸기 |
| X / Esc | 취소 |
| Enter | 메뉴 (도감 · 기록 · 저장 · 소리) |

저장은 브라우저(localStorage)에 된다. 집(수소 마을 오른쪽 집) 문, 원소 연구 센터, 또는 메뉴 → 저장.

## 퀴즈 채집 규칙

- 마을은 **족(族)별**로 나뉘어 있고, 마을마다 **그 족의 원소만** 나온다.
- 풀숲·광석·해초·유황 바위·네온 골목을 걸으면 **자연 상태의 원소**가 나타난다. 처음엔 **실루엣과 "???"**만 보여서 어떤 원소인지 모른다.
- 정체를 맞히는 문제("이 원소는 무엇일까?")가 나온다. 보기는 **같은 족 원소 이름**이다.
- **맞히면 정체가 밝혀지고 채집**된다. 한 문제에 기회 2번(틀린 보기는 지워짐). 둘 다 틀리면 정체와 해설을 보여 주고 원소는 도망간다. 다시 만나면 **다른 문제**가 나온다.
- 이미 채집한 원소는 다시 나오지 않는다.
- 마을의 원소를 **모두 채집하면 문지기가 비켜서** 동쪽(다음 족) 마을로 갈 수 있다.
- **힌트 전구**: 틀린 보기 2개를 지운다. 처음 3개 + 마을 사람 선물 + 퀴즈 대결 승리로 얻는다.
- 트레이너는 **퀴즈 대결**: 그 마을 원소의 정체 맞히기 3문제 중 2개 이상 맞히면 승리.

### 문제 구성 (원소마다 6개, 만날 때마다 차례로)
- **실생활 수수께끼 3개** (직접 작성, `src/data/quiz.ts`): 쓰임새·생활 속 현상·이름의 유래가 단서. 문제에 원소 이름은 절대 나오지 않는다.
- **단서 문제 3개** (자동 생성, `src/systems/quiz.ts`): 원소 기호 / 주기·족 위치 / 원자 번호를 보고 원소 맞히기

문제를 고치거나 늘리려면 `src/data/quiz.ts` 에 `Q('문제', '해설')` 형식으로 추가하면 된다. 정답은 항상 그 원소이고, 오답 보기는 같은 족에서 자동으로 고른다.
설명이 같은 족의 다른 원소에도 맞을 수 있으면 세 번째 칸에 그 원소 번호를 넣어 오답에서 빼 준다. 예: `Q('수돗물을 소독하는 원소는?', '…', [35])` (브로민도 소독에 쓰이므로 제외)

## 수업에서 다룰 수 있는 개념

| 게임 요소 | 화학 개념 |
|---|---|
| 분류 8종 | 원소 분류 (알칼리 금속 · 알칼리 토금속 · 전이 금속 · 전이후 금속 · 준금속 · 비금속 · 할로젠 · 비활성 기체) |
| 실생활 수수께끼 108개 | 생활 속 원소 (배터리의 리튬, 치약의 플루오린, 과자 봉지의 질소, 반도체의 규소 …) |
| 족별 마을 · 같은 족 보기 | 같은 족 원소끼리의 공통점과 차이 (최외각 전자 수), 주기율표의 배열 |
| 마을 기온 + 채집 후 상태 안내 | 녹는점·끓는점과 상태 변화 (예: 화산 600 K에서 황은 액체) |
| 몬스터 모양 | 몸 모양=분류, 크기=원자 반지름, 궤도 위 점 개수=원자가 전자 수, 색=실제 색/불꽃 반응색 |
| 도감 상세 | 실생활 용도 3가지, 재미있는 사실, 전자 배치, 발견 연도·발견자, 물성 |

## 마을과 진행 — 주기율표를 왼쪽에서 오른쪽으로

```
1족 → 2족 → 3~12족 → 13족 → 14족 → 15족 → 16족 → 17족 → 18족
```

| 마을 | 원소 | 분위기 · 기온 |
|---|---|---|
| 1족 알칼리 금속 마을 (시작) | H Li Na K | 마을 · 20 ℃ (수소는 1족이지만 비금속!) |
| 2족 알칼리 토금속 마을 | Be Mg Ca | 조개 해변 · 27 ℃ |
| 3~12족 전이 금속 마을 | Sc Ti V Cr Mn Fe Co Ni Cu Zn | 광산 · 15 ℃ |
| 13족 붕소족 마을 | B Al Ga | 공업 단지 · 25 ℃ |
| 14족 탄소족 마을 | C Si Ge | 숲 · 18 ℃ |
| 15족 질소족 마을 | N P As | 농장 · 20 ℃ |
| 16족 산소족 마을 | O S Se | 화산 · 327 ℃ |
| 17족 할로젠 마을 | F Cl Br | 염전 · 32 ℃ |
| 18족 비활성 기체 마을 | He Ne Ar Kr | 네온 도시 · 25 ℃ |

저장: 1족 마을 집, 13족·18족 원소 연구 센터, 또는 메뉴 → 저장. 진행 상황: 1족 마을 주기 박사 / 메뉴 → 기록.

## 그림에 대해

외부 이미지 파일이 없다. 모든 도트 그림(원소 몬스터 36종, 타일, 캐릭터, 아이콘)은 `src/art/` 의 코드가 원소 데이터를 바탕으로 생성한다.
AI가 생성한 도트 이미지로 바꾸고 싶으면 `public/` 에 PNG를 넣고 `BootScene` 에서 같은 키(`mon_8` 등)로 불러오면 된다.

## 폴더 구조

```
src/
  data/       elements.ts (원소 36종 + 족별 마을 구분) · quiz.ts (실생활 수수께끼 108개) · types.ts (분류) · areas.ts (9개 족 마을 맵·NPC)
  systems/    quiz.ts (문제 만들기·섞기) · state.ts (저장) · audio.ts (칩튠 효과음·배경음)
  art/        monsters.ts · tiles.ts · chars.ts · icons.ts  (도트 그림 생성)
  scenes/     Boot · Title · Intro · Overworld · Quiz · Summary · Dex
  ui/         ui.ts (GBA 창, 대화창, 메뉴, 입력)
```

개발용: 주소 뒤에 `?debug` 를 붙이면 창이 가려져도 게임이 돌아가고 `window.__game`, `window.__dbg` 로 상태를 볼 수 있다.
